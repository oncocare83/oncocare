# Onco Care website

## To change anything on the site
1. Open this project on github.com and click **content.js**.
2. Click the ✏️ pencil icon (top right of the file).
3. Change the words between the quote marks or backticks. Don't delete the marks themselves.
4. Click **Commit changes** (green button) → **Commit changes** again.
5. Wait about a minute and refresh the website. Done.

## Writing tips (inside the long text boxes)
- Empty line = new paragraph
- Start a line with `- ` = bullet point
- `**words**` = **bold**

## To add a picture
1. Open the **images** folder → **Add file** → **Upload files** → drag the photo in → **Commit changes**.
2. In content.js, type its name, e.g. `image: "images/my-photo.jpg",`

## To add a new blog post
In content.js, copy one whole post (from `{` to `},`), paste it right below, and change the title, image and text.

## If the site breaks
Usually a missing quote mark or comma. On GitHub, open content.js → **History** to see the previous version and copy it back.
